Every button

What each control does

Touch Down

Reveals the real winner

Shows the closest submitted guess on the public winner board. If nobody has guessed yet, it says there is no winner yet.

Mask Winner

Shows the fake winner

Displays Teddy-Tami-Tili-Guchi-Damien instead of the real closest guess. Use it as a joke or to stall before the reveal.

Hide Winner

Hides the winner board result

Returns the board to the waiting state, so guests do not see the winner yet.

Disable Guess Tab

Closes guessing

Turns off public guess submissions. The same button changes to Enable Guess Tab when guessing is closed.

Reset Game

Clears all ages and guesses

Starts over from a blank round. The browser asks you to confirm before it clears the game.

Log out

Closes your admin session

Hides the dashboard and returns your device to the admin sign-in screen.

Where to look

Screen areas and expected states

Top status

You should see Checking session..., then Live updates connected after sign-in. If it says reconnecting, leave it open; it will keep trying.

Metric cards

Age total is private and should not be shown to guests. Players counts saved ages. Guesses counts saved total-age guesses.

Winner board

Before the reveal it says Ready for the reveal. After Touch Down it shows the winning name, their guess, and how far away it was.

Game controls

Use these in order during a normal round: leave guessing enabled, wait for guests, press Disable Guess Tab, then press Touch Down.

Guest QR

The QR code and link point guests to the same game URL. Keep this visible while people are joining.

Live lists

The age list tells you who has checked in. The guesses list tells you who finished the second step.

Run of show

The simple host flow

  1. Open /host and sign in with the admin password.
  2. Show guests the QR code so they can enter their age.
  3. Watch Players until everyone has checked in.
  4. Tell everyone to switch to Sum of Ages and submit one guess.
  5. Watch Guesses, then press Disable Guess Tab.
  6. Press Touch Down to reveal the closest guess.
  7. Press Reset Game only when you want a brand-new round.
